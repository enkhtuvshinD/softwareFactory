# Mira Chen — Designer

Build a responsive one-page portfolio for a freelance product designer named
Mira Chen. Include a short introduction, three clearly labeled sample project
cards, an About section, and a contact link using mailto. Navigation scrolls
to sections, works by keyboard, and is readable on phones. The sample project
descriptions should be identified as demonstration content rather than claims
about real clients. Use a coherent visual style and intentional artwork or
CSS treatments that do not depend on remote image availability.

This is static presentation. Do not add accounts, commerce, a dashboard,
booking, a submission form, or external integrations.
